## Run it

```sh
python3 main.py
```

`main.py` copies the image in `assets/news-20261123.png` to `/output/entry.png` (or `./output/entry.png` when run locally), byte-for-byte, so every run writes identical bytes. No network, no randomness, Python standard library only. The image itself was drawn by `tools/build_image.py`.
